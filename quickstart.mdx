## Prerequisites

- An NCZ Silver, Gold or Platinum plan
- A Customer API key for your company

## Make your first call

<Steps>
  <Step title="Get an API key">
    Ask your NCZ account manager for a key. It is shown once, so store it in a secret manager straight away.
  </Step>
  <Step title="Call the API">
    Send the key in the `x-api-key` header:

    ```bash
    curl https://api.nczgroup.com/v1/company \
      -H "x-api-key: YOUR_API_KEY"
    ```

    A `200` response with your company profile means the key works.
  </Step>
  <Step title="List your suppliers">
    ```bash
    curl "https://api.nczgroup.com/v1/suppliers?limit=10" \
      -H "x-api-key: YOUR_API_KEY"
    ```

    Use a supplier `id` from this list to call [Get supplier certification](/api-reference/suppliers/compliance) on Gold, or check [webinar registrations](/api-reference/webinars/registrations) on Platinum.
  </Step>
</Steps>

<Tip>
  Getting `401`, `403` or `429`? See [Errors](/api-reference/errors).
</Tip>
