---
title: "List suppliers"
description: "Returns your active suppliers, newest first."
api: "GET /v1/suppliers"
tag: "Silver"
---

To read every supplier, increase `offset` by `limit` until `offset` reaches `pagination.total`.

<ParamField query="limit" type="integer" default="50">
  Number of suppliers to return, from 1 to 200.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of suppliers to skip.
</ParamField>

<ResponseField name="data" type="object[]" required>
  Suppliers. Each item has the same shape as [Get supplier](/api-reference/suppliers/get).
</ResponseField>

<ResponseField name="pagination" type="object" required>
  <Expandable title="properties">
    <ResponseField name="total" type="integer">Total suppliers across all pages.</ResponseField>
    <ResponseField name="limit" type="integer">Limit applied to this page.</ResponseField>
    <ResponseField name="offset" type="integer">Offset applied to this page.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.nczgroup.com/v1/suppliers?limit=2&offset=0" \
  -H "x-api-key: YOUR_API_KEY"
```
</RequestExample>
