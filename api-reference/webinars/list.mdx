---
title: "List webinars"
description: "Returns your webinars with registration, attendance and feedback counts."
api: "GET /v1/webinars"
tag: "Platinum"
---

<ResponseField name="data" type="object[]" required>
  Webinars. Each item has the same shape as [Get webinar](/api-reference/webinars/get).
</ResponseField>

<RequestExample>
```bash cURL
curl https://api.nczgroup.com/v1/webinars \
  -H "x-api-key: YOUR_API_KEY"
```
</RequestExample>
